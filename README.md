# mcp2cli

Turn any MCP server, OpenAPI spec, or GraphQL endpoint into a CLI — at runtime, with zero codegen.

## Quick start

```bash
# Run directly without installing
uvx mcp2cli --help
# Or install globally
uv tool install mcp2cli
```

```bash
npx skills add knowsuchagency/mcp2cli --skill mcp2cli
```
